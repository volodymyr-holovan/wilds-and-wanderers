# Wilds & Wanderers

Українська збірка модів для **Minecraft 1.21.1 (NeoForge 21.1.264)** про мандри, пригоди й поступовий розвиток: дракони й динозаври, Сутінковий ліс і Етер, магія Ars Nouveau та Iron's Spells, техніка Create, Mekanism й AE2, села, колонії й мандрівники з дорученнями. Уся збірка перекладена українською, а книга квестів, вікі й підказки написані для гравців, які не читають англійських гайдів.

*A Ukrainian-language NeoForge 1.21.1 adventure modpack. This repository holds the pack's own work (configs, quests, scripts, translations and two small mods); the 170+ mods it uses are listed in `docs/mods.json` with their download links.*

## Що тут особливого

- **Один інвентар на все.** Клавіша E відкриває одне вікно зі слотами всіх модів (каблучки, рукавиці, пояс, плащ, ранець, книга заклинань…). Поруч, без перекриття, відкриваються книга рецептів і панель характеристик. Предмети різних модів одного виду лежать в одному слоті.
- **Мандрівники з дорученнями.** 72 персонажі в спорудах світу, 100 доручень українською з історіями; дехто дає цілий ланцюжок (до 5 справ). Знак «!» над головою — у мандрівника є справа для вас. Кожен гравець виконує доручення окремо.
- **Дерево навичок.** Досвід за дослідження, бої, видобуток і квести; вісім гілок: воїн, мисливець, маг, майстер, мореплавець, слідопит, дипломат, торговець.
- **Книга квестів.** 22 розділи, понад 440 квестів: від перших кроків до термоядерного реактора, драконів і босів. У кожному квесті сказано, де взяти потрібні речі.
- **Вікі в грі** (клавіша O): біоми, споруди, моби, предмети, звідки що падає, як моди пов'язані між собою.
- **Музика, що підлаштовується**: спокій, бій, теми босів.
- **Одна система замість кількох**: однакові руди й злитки зведено до одного предмета, мана Ars Nouveau та Iron's Spells спільна, валюти — смарагди й гоблінські монети, і мандрівні торговці завжди міняють одне на інше.

## Склад репозиторію

| Тека | Що там |
|---|---|
| `pack/overrides/` | Усе, що кладеться поверх модів у теку гри чи сервера: `config/`, `defaultconfigs/`, `kubejs/` (рецепти, теги, переклади, дані квестодавців). |
| `pack/overrides-initial/` | Налаштування, які копіюються лише раз (відео, мінімапа, клавіші): далі гравець змінює їх сам. |
| `pack/removed.txt` | Що збірка більше не постачає; `sync_overrides.py` відкладає це в `_removed_by_pack/`, нічого не видаляючи. |
| `pack/tools/` | Скрипти збірки: завантаження модів (`build_neo.py`), генератори квестів (`quests/`), квестодавців (`npc/`), дерева навичок, шрифтів, переклад (`i18n/`), тести на локальному сервері. |
| `pack/i18n/uk/` | Українські переклади модів (готові файли — у `pack/overrides/kubejs/assets/*/lang/`). |
| `mods-src/wilds_core/` | Власний мод **Wilds Core**: квестодавці, навички й досвід, музика, екран спорядження, обмін валют. |
| `mods-src/wilds_wiki/` | Власний мод **Wilds Wiki**: вікі в грі. |
| `docs/` | Список модів із посиланнями й контрольними сумами (`mods.json`), чому обрано саме ці моди (`вибір-модів.md`), зліпки реєстрів сервера. |

## Як зібрати

Потрібні Python 3.11+, Java 21 і встановлений NeoForge 21.1.264.

1. Завантажити моди (точно ті версії, що в `docs/mods.json`):
   ```
   python pack/tools/build_neo.py <тека-збірки>
   ```
   Моди ляжуть у `<тека-збірки>/client/mods` і `<тека-збірки>/server/mods`.
2. Зібрати власні моди (`javac` проти бібліотек лаунчера, без Gradle):
   ```
   python mods-src/wilds_core/build.py
   python mods-src/wilds_wiki/build.py
   ```
3. Скопіювати налаштування в теку гри чи сервера:
   ```
   python pack/tools/sync_overrides.py <тека гри>
   python pack/tools/sync_overrides.py <тека сервера> --no-initial
   ```

Квести, квестодавці й дерево навичок генеруються з Python-описів: `pack/tools/quests/gen_quests.py`, `pack/tools/npc/gen_npc.py`, `pack/tools/gen_skilltree.py`. Генератори звіряють кожен предмет, моба й споруду з реєстрами сервера в `docs/registries/`.

Деякі скрипти (тести на локальному сервері, встановлення в теку гри) мають шляхи до тек на комп'ютері автора — поправте їх під себе.

## Моди

Повний список зі сторінками й версіями — `docs/mods.json`; огляд за ролями — `docs/вибір-модів.md`. Моди належать їхнім авторам і в репозиторії не зберігаються.

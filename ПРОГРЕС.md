# Wilds & Wanderers — NeoForge 1.21.1: журнал робіт

Рішення власника (23.10.2026): перехід із Fabric 26.3 на **NeoForge 1.21.1** заради Create, Mekanism, Ars Nouveau, Iron's Spells, драконів і динозаврів. Музика тільки вільна (Reactive Music). Світ новий. Fabric-сервер 26.3 у Crafty лишається вимкненим як резерв.

## Структура папки
- `pack/overrides/` — усе, що додає збірка поверх модів (config, kubejs). **Джерело правди** для сервера, клієнта й майбутнього лаунчера.
- `pack/tools/` — скрипти: `gen_skilltree.py` (дерево навичок), `fix_nomadictents_advancements.py`, `sync_overrides.py <папка>` (копіює оверрайди), `rcon.py`.
- `server/mods`, `client/mods`, `optional/client-mods` — jar-файли (список у `docs/mods.json`).
- `testserver/` — локальний тестовий сервер (NeoForge 21.1.264, Java 21 з `_tools/java21`), RCON 127.0.0.1:25580 (пароль у `_tools/test_rcon_password.txt`).

# The Twilight Forest — completion of the Final Castle

The pack's build of [The Twilight Forest](https://github.com/TeamTwilight/twilightforest) 4.8.3345 with the Final Castle
finished: the Rune Sovereign in the gazebo, the Forge Harbinger in the forge, the castle's mobs, the Roving Cube caught
with the Talisman of the Cube, the Cube of Annihilation, and a fix to the castle's dungeon generation. This is a fan
completion for Wilds & Wanderers, not TeamTwilight's own design. Design and tests (in Ukrainian):
[`docs/twilight-forest-completion/`](../../docs/twilight-forest-completion/).

```bash
python mods-src/twilightforest-completion/build.py --install
```

Clones TeamTwilight's repository, checks out `008085c` (the commit 4.8.3345 was built from), applies `patches/` with
`git am`, builds with Gradle under a JDK 21 and puts `wilds_twilightforest-1.21.1-4.8.3345-w2.jar` into `client/mods`,
`server/mods` and `testserver/mods` (the official jar there is renamed to `*.jar.replaced`).

To change the completion: build once, work in `_tools/twilightforest-src` on the branch `wilds-completion`, rebuild with
`--no-prepare`, then commit and regenerate the patches with `git format-patch --binary 008085c..HEAD -o patches/`.
Models and their textures come from `tools/make_models.py <TF checkout>` (it rewrites the geometry between the
`// ---- generated by make_models.py` markers of the model classes); `tools/make_textures.py` draws the scepter and
the bolt.

# Квест «Нарізка»
`Книга квестів → **Кухня**`

Покладіть продукт на **нарізну дошку** і клацніть по ній ножем. Капуста дає листя, шматок свинини — бекон, курка — шматочки.
Порізане м'ясо смажиться швидше й стає основою для страв.

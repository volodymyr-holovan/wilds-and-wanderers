# Квест «Провісник»
`Книга квестів → Великі боси`

**Провісник** — механічний висохлий з Катаклізму, сторож руїн у глибинах. Стріляє лазерами й ракетами, вибухає при наближенні. Тримайтеся на відстані, ховайтеся за колонами від лазера. Нагорода — **вітерит** для зброї.

- **Де:** **Стародавня фабрика** глибоко під землею.
- **Складність:** ★★★★★
- **Що взяти:** незеритова броня з «Захистом від вибухів», молоко від висихання
- **Як знайти:** **Механічне око** (блоки редстоуну, залізо, око Енду) або Компас дослідника → «ancient_factory».
- **Порада:** ховайтеся за колонами від лазера — він б'є по прямій.

# Квест «Вони повернулися»
`Книга квестів → **Доручення**`

**Панас**, дзвонар (доручення 3 з 3):
«Ті самі розбійники, що вкрали старий дзвін, повернулися по новий. Учора вночі я бачив їхні смолоскипи на пагорбі.»
Переможіть шістьох розбійників, що підбираються до села.

Нагорода — у замовника: поверніться до нього, коли виконаєте.

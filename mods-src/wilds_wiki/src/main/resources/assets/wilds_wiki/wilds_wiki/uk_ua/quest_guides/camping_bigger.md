# Квест «Більша юрта»
`Книга квестів → **Похідне життя**`

Юрту збільшують на верстаку: **юрта + секції** дають наступний розмір.
• крихітна → мала: юрта в центрі, 3 секції навколо;
• мала → середня: ще 3 секції;
• середня → велика: 3 секції + 2 **золоті поперечки**;
• велика → гігантська: 3 секції + 2 **обсидіанові поперечки**; гігантська → мега: **алмазні поперечки**.

**Наметові лопати** (кам'яна, залізна, золота, обсидіанова, алмазна) додають **шари** — ширшу підлогу всередині.

- **Порада:** так само будуються типі (зі шкіри), бедуїнський намет (вовна), шаміяна й ідлу (з листя) — кожен виглядає інакше.

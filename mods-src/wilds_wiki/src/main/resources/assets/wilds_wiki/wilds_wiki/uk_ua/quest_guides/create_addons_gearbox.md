# Квест «Латунний редуктор»
`Книга квестів → **Create: додатки**`

Create: Connected додає дрібні, але корисні кінетичні деталі. У **латунного редуктора** напрям обертання кожної з чотирьох сторін окремо перемикається ключем.
**Відцентрова муфта** з'єднує вали, лише коли обертання досить швидке.

# Квест «Джерело»
`Книга квестів → Ars Nouveau`

**Джерело** (source) — магічна рідина для машин Ars. Його виробляють **джерельні зв'язки**: вулканічний (з палива), агрономний (з росту рослин), віталічний (з народжень тварин), міцелієвий (з їжі), алхімічний (із зілля). Зберігають у **глечиках джерела**.

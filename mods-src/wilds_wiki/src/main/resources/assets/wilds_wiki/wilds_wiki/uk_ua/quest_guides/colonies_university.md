# Квест «Університет»
`Книга квестів → **Села й колонії**`

**Університет** відкриває дослідження: кращі інструменти поселенців, швидшу роботу, нові будівлі (кузня, плавильня, алхімік, лікарня).
**Стародавні книги** з підземель потрібні для деяких досліджень.

# Квест «Автоматичний завод»
`Книга квестів → **Create**`

**Заводський датчик** планує виробництво: ви кажете «тримай 64 точні механізми», і він сам замовляє сировину зі складу, відправляє на машини й складає готове.
Це вершина Create: завод, що працює без вас.

# Квест «Пальник-зачарувальник»
`Книга квестів → **Create: додатки**`

**Пальник-зачарувальник** зачаровує предмети на конвеєрі, витрачаючи рідкий досвід — без столу зачарувань і без втрати рівнів гравця.
Шаблон зачарування задає, що саме накласти.

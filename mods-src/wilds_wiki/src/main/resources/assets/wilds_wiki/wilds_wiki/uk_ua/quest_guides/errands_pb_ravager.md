# Квест «Звір облоги»
`Книга квестів → **Доручення**`

**Ярема**, колишній солдат (доручення 3 з 4):
«Того дня ворота нашої застави виламав руйнівник — звір завбільшки з хату. Він приходить із великими набігами.»
«Кажуть, той самий звір досі ходить з їхнім військом. Я впізнаю його по шраму на морді.»
Переможіть руйнівника.

**Обіцяна плата: **[[minecraft:saddle]], [[minecraft:emerald]] ×14, 300 досвіду, скриня здобичі, 120 очок шляху
Плату видає замовник: поверніться до нього, коли виконаєте.

# Квест «Вентилятор»
`Книга квестів → **Create**`

Вентилятор дме крізь блок перед собою й обробляє предмети на шляху: крізь **воду** — промивка, крізь **лаву чи вогонь** — плавлення, крізь **вогонь душ** — «привидіння», крізь **багаття** — копчення.

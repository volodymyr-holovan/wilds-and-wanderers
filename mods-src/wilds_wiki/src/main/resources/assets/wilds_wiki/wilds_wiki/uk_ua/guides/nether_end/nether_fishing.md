# Рибалка в лаві (Nether Depths Upgrade)
Лавові моря Незеру живі: у них плавають дев'ять видів риб, ростуть багряна й химерна ламінарія та морська трава.

- Для лави потрібна [[netherdepthsupgrade:lava_fishing_rod]] — з незеритових уламків, стрижнів іфрита й ланцюгів.
!recipe netherdepthsupgrade:lava_fishing_rod
- Улов — лавові риби, рідше — скарби: золото, сідла, книги, навіть черепи візер-скелетів.

# Що робити з рибою
- [[netherdepthsupgrade:blazefish]] → порох іфрита; [[netherdepthsupgrade:glowdine]] → світлопил; [[netherdepthsupgrade:obsidianfish]] → обсидіан; [[netherdepthsupgrade:searing_cod]] → вугілля; [[netherdepthsupgrade:bonefish]] → кісткове борошно. Блейзрибу й світлосардину жорна Create мелють удвічі вигідніше.
- [[netherdepthsupgrade:eyeball_fish]] + ножиці → [[netherdepthsupgrade:eyeball]]; око + порох іфрита → **око Енду**. Це другий шлях до порталу в Енд, без ендерменів.
- [[netherdepthsupgrade:fortress_grouper]] + ножиці → [[netherdepthsupgrade:fortress_grouper_plate]]; пластини з очима й склом дають [[netherdepthsupgrade:lava_glass]].
- [[netherdepthsupgrade:soulsucker]] + ножиці → [[netherdepthsupgrade:soul_sucker_leather]] → [[netherdepthsupgrade:soul_sucker_boots]].
- З кількох [[netherdepthsupgrade:wither_bonefish]] складається троянда візера.
> Є й зілля та стріли «лавового зору» — для тих, хто пірнає в лаву з вогнестійкістю.

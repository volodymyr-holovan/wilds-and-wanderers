# Квест «Цинк»
`Книга квестів → **Create**`

**Цинкова руда** — зеленувато-сіра, трапляється в глибокому сланці й поруч із ним (нижче 0 висоти). Цинк потрібен для латуні й багатьох механізмів Create. Подрібніть руду жорнами чи дробильними колесами — вийде більше злитків.

# Квест «Черепи візер-скелетів»
`Книга квестів → **Доручення**`

**Некромант Гордій**, дуже підозрілий науковець:
«Мені потрібні три черепи візер-скелетів. Для науки. Суто для науки. Ні, я не збираюся нікого воскрешати. Чого ви так дивитеся?»
Принесіть три черепи візер-скелетів. Чари «Грабунок» на мечі додають шансу.

Нагорода — у замовника: поверніться до нього, коли виконаєте.

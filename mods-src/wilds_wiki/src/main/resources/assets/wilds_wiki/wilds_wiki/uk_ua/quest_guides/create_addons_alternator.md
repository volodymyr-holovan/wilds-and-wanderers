# Квест «Генератор»
`Книга квестів → **Create: додатки**`

**Альтернатор** перетворює обертання Create на енергію FE. Так ваше водяне колесо чи паровий двигун можуть живити машини **Mekanism** і мережу **AE2**.
Енергію передають дроти між **конекторами** або кабелі Mekanism.

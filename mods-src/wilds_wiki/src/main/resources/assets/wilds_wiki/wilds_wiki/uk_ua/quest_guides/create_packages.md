# Квест «Пакунки»
`Книга квестів → **Create**`

Create 6 пакує предмети в **картонні пакунки** з адресою. **Пакувальник** запаковує, конвеєри й жабки-перевізники (**frogport**) несуть пакунок куди слід, а там його розпаковують.

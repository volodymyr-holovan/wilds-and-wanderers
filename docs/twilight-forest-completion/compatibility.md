# Сумісність зі збіркою

Перевірено на повній збірці (182 моди, `docs/mods.json`), якщо не сказано інакше.

| Мод / система | Що могло зачепити | Висновок |
|---|---|---|
| **Sable 2.0.6** (Create Aeronautics) | Тікет TF #2604 / sable#387: сервер падав біля Кінцевого замку через `ForceFieldBlock.getShape()` | Не відтворилось (див. [testing.md](testing.md)). `ForceFieldBlock` лишено без змін |
| **Open Parties and Claims** | Куб знищення міг стирати блоки в приватах | Куб подає `BlockEvent.BreakEvent` лише для блоків, які стер би; OPAC може скасувати. В грі не перевірено |
| **GriefLogger** | Хибні записи ламання | Подію подаємо лише для справді знищуваних блоків |
| **Lootr / Corpse / рюкзаки** | Куб міг з'їсти скриню з вмістом | Блоки з вмістом Куб не чіпає ніколи |
| **Apotheosis, Iron's Spells, Ars Nouveau, Cataclysm, Mekanism** (сильна зброя) | Боса вбивають одним ударом | Ліміт 30 за удар; броня боса 12/6 |
| **Create** (deployer — «фальшивий гравець»), турелі, пастки | Автоматичне вбивство боса | Шкода без живого гравця ×0,25; нападник має бути в арені й ближче 24 блоків |
| **Iron's Spells, Ars Nouveau** (телепорти) | Пройти в альтанку без Куба знищення | Не заблоковано: заборонити телепорти чужих модів надійно не вийде. Бій від цього не змінюється, лише пропускається ловіння куба |
| **Wilds Core: KillCredit** | Зарахування вбивств квестам | Квест на Передвісника — `kill`, працює через KillCredit. Квест на Володаря — досягнення `progress_final`, яке бос сам видає всім учасникам |
| **Wilds Core: PartyPeace** | Друзі не б'ють одне одного | Не перетинається: удари лише по босах |
| **Wilds Core: OpBreak** | Оператор ламає захищені блоки TF | Спавнери нових босів у тегах захисту TF, як і решта |
| **TF `multiplayerFightAdjuster = NONE`** (налаштування збірки) | Штатна поправка TF на групу вимкнена | Нові боси мають власну поправку (+40 % здоров'я, додаткові талісмани й скіпетри), решта босів TF без змін |
| **Twilight Forest Final Boss (Remake)** | Другий фінальний бос | У збірку не ставимо (див. [fan-projects.md](fan-projects.md)) |
| **Small Ships** | Попередження про моделі `twilightforest_*` човнів у журналі клієнта | Існували й раніше, не пов'язані |
| **Лаунчер збірки** | Два TF у гравця після оновлення | Лаунчер відсуває файли, яких немає в новому маніфесті: офіційний TF зникне, `wilds_twilightforest-*.jar` прийде з релізу. Перевірено читанням коду (`PackSync.cs`), не запуском |
| **build_neo.py / release_client.py** | Повернення офіційного TF при оновленні модів | TF має `"where": "replaced"`: не завантажується й не роздається; наш jar — власний мод (`wilds_*`) |
| **Crafty** (продакшн) | `bundle_changes.py` не копіює jar | Jar на сервер треба заливати вручну (див. ПРОГРЕС.md): перейменувати `twilightforest-…universal.jar` → `.replaced`, залити `wilds_twilightforest-…-w1.jar`. **Не зроблено: заливка лише на прохання власника** |
| **Збереження продакшну** | Старі замки, підкорені замки | Оновлення на льоту змінює лише кілька блоків маркера, альтанки й кузні; підкорені замки отримують лише прибирання написів |
